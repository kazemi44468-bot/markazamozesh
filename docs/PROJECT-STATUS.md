## Design Rules — Permanent
- Light theme is mandatory by default.
- Avoid dark navy / saturated blue backgrounds as primary surfaces.
- Use clearly differentiated white/surface cards, borders and subtle shadows.
- Persian local fonts are preferred; local font files live in the project font directory.
- RTL and mobile-first are mandatory.
- AI must be treated as a product layer, not only a chat screen.
- Demo content must be replaceable by API data later.

## Gate 0 — Exit Criteria
Phase 0 is complete when Product Architecture, Domain Model, Information Architecture, User Flows, Technical Architecture, AI Strategy, Master Roadmap and UX Principles are approved.
