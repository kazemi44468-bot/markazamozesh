# UX Principles

## 1. Person first
Dashboard and recommendations start from the learner's goal and current state.

## 2. Mobile first
Design for one-hand use, short sessions, touch targets, bottom navigation and fast resume. Desktop adds workspace density rather than redefining the product.

## 3. Progressive disclosure
Show the next useful action first; advanced controls remain available without overwhelming beginners.

## 4. Learning clarity
At any point the learner should know: where am I, why am I here, what have I learned, what remains and what should I do next?

## 5. Accessibility
Semantic structure, keyboard access, focus management, contrast, captions/transcripts and reduced-motion considerations are baseline requirements.

## 6. Trust
Certificates, scores, AI-generated feedback and recommendations must have clear provenance and status.

## 7. AI as copilot
AI suggests and assists; users retain meaningful control. The interface must distinguish generated output from verified system records.

## 8. States
Every significant component has loading, empty, error, disabled, success and permission-denied states where applicable.

## 9. Performance
Learning content should load quickly on constrained mobile connections. Video, images and scripts must be optimized.

## 10. Design System
Typography, spacing, color, elevation, radius, forms, cards, navigation, dialogs, tables, charts and feedback components are shared across product surfaces.

## 11. Content design
Persian RTL is first-class. Copy should be concise, action-oriented and understandable; technical terms may be used where they improve precision.

## 12. Navigation
Public website navigation is conversion-oriented. Learner navigation is task-oriented. Admin navigation is management-oriented. Never force one navigation model onto all personas.
