# Master Roadmap

## Phase 0 — Strategy & Architecture
**Goal:** freeze the product direction before implementation.

Deliverables:
- Master Strategy
- Product Architecture
- Domain Model
- Information Architecture
- User Flows
- Technical Architecture
- AI Strategy
- UX Principles
- Product requirements baseline

Gate: documents reviewed and approved; no unresolved architecture contradiction.

## Phase 1 — UX & Design System
Deliverables:
- Personas
- user journeys
- sitemap confirmation
- wireframes
- visual direction
- Persian typography
- color/token system
- responsive grid
- component library
- accessibility rules
- website prototype
- learner dashboard prototype

Gate: core flows usable on mobile and desktop.

## Phase 2 — Education Core
Deliverables:
- identity/auth
- users/profiles
- roles/permissions
- organizations foundation
- course/curriculum model
- enrollment
- progress
- media
- notifications foundation
- audit foundation
- API baseline

Gate: domain operations work without UI coupling.

## Phase 3 — Learner MVP
Website + auth + onboarding + profile + courses + lessons + progress + quiz + basic certificate + learner dashboard.

Gate: end-to-end learner can register, select goal, enroll, learn, complete and receive certificate.

## Phase 4 — Instructor + Admin
Course builder, content management, assessments, student management, analytics, admin governance.

## Phase 5 — Organization / SaaS
Multi-tenant organization, departments, members, learning programs, assignments, reports, subscription/billing foundation.

## Phase 6 — Skills / Credentials
Skill taxonomy, skill evidence, skill-gap, learning paths, projects, advanced certificates and public verification.

## Phase 7 — AI Learning
AI Gateway, contextual learner assistant, instructor assistant, knowledge retrieval, quiz/content assistance, AI evaluation and cost controls.

## Phase 8 — Marketplace / Mentor
Instructor commerce, mentor marketplace, orders, commissions, reviews and human mentoring.

## Phase 9 — Mobile / Advanced AI
PWA hardening, native apps if justified, adaptive learning, advanced agents, enterprise AI and cross-product identity integrations.

## Delivery discipline
Each phase has a gate. A phase is not complete because files exist; it is complete when its acceptance criteria pass and PROJECT-STATUS is updated.

## Priority rule
Customer value and platform foundations precede visual expansion. Do not build low-value admin or marketplace features before the learning loop works.
