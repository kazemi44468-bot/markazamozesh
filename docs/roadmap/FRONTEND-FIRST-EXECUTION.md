# Frontend-First Execution Plan

## تصمیم
مرکز آموزش از این مرحله به بعد با دو مسیر موازی توسعه می‌یابد:

### Track A — Visible Product
ساخت سریع Frontend، صفحات عمومی، محتوای Demo و Prototypeهای قابل مشاهده برای اعتبارسنجی تجربه.

### Track B — Product Foundation
تکمیل معماری، Domain، API contracts، AI، امنیت و داده در پشت صحنه.

این دو مسیر نباید یکدیگر را متوقف کنند.

## Demo-first rule
تا زمان آماده شدن Backend، صفحات با mock data و stateهای واقعی طراحی می‌شوند. هیچ محتوای Demo نباید به‌عنوان داده واقعی یا نتیجه واقعی کاربر معرفی شود.

## Definition of Done برای هر صفحه

- Mobile
