# Frontend MVP Plan — مرکز آموزش

## هدف
ساخت سریع یک نمونه قابل مشاهده از مرکز آموزش، هم‌زمان با تکمیل معماری محصول. این Track مستقل از Backend است و با Demo Content پیش می‌رود.

## اصل اجرا
Frontend-first, mobile-first, content-first, AI-ready.

## Definition of Done برای هر صفحه
- RTL و فارسی
- Responsive واقعی
- Mobile-first
- Header/Footer سازگار
- حالت‌های اصلی UI
- Demo content واقعی و قابل جایگزینی
- CTA و navigation مشخص
- دسترسی‌پذیری پایه
- SEO metadata برای صفحات عمومی
- عدم وابستگی به Backend در نسخه Demo

## Parallel Architecture Track
هم‌زمان با Frontend:
- Domain Model
- Information Architecture
- User Flows
- Technical Architecture
- AI Architecture
- Design System

## Release هدف
در پایان Frontend MVP باید یک مسیر کامل Demo وجود داشته باشد:
Home → Services → Platform → Courses → Course Detail → Consultation

و یک مسیر محصول:
Onboarding → Learner Dashboard → Learning Path → Lesson → AI Companion → Certificate.
