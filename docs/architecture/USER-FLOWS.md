# User Flows

## Learner acquisition
Website → Course/Platform → Register → Onboarding → Goal → Interests → Diagnostic Assessment → AI/Rules Analysis → Personalized Learning Path → Dashboard.

## Learning loop
Goal → Recommended Path → Course → Lesson → Practice → Assessment → Skill Evidence → Progress → Next Recommendation.

## Mobile micro-learning
Notification → Daily Learning → Micro Lesson → Quick Practice → Feedback → Streak/Progress → Next item.

## Course completion
Course → Required Lessons → Assessments → Project (if applicable) → Completion Rule → Certificate → Learning Identity update → Share/Verify.

## Instructor
Register → Instructor onboarding → Profile/verification → Create Course → AI-assisted curriculum → Content → Quiz/Assignment/Project → Review → Publish → Student management → Analytics → Iteration.

## Organization
Consultation/Demo → Tenant creation → Organization admin → Departments → Members → Learning program → Course assignment → Assessment → Reports → Skill-gap analysis → Intervention.

## Mentor
Mentor onboarding → Profile → Availability → Learner matching → Session → Notes → Feedback → Skill evidence.

## AI interaction
User action → Context assembly → Authorization → Agent selection → Knowledge retrieval/tools → Response/action → User feedback → Analytics/evaluation. AI must never bypass permission boundaries.

## Certificate verification
Public URL/QR → Certificate lookup → Signature/status validation → Public verification result.

## Commerce
Course/Plan → Cart/Checkout → Payment → Order confirmation → Enrollment/Subscription activation → Receipt → Learning access.

## Support
Help Center → Search/FAQ → Guide → If unresolved: Ticket → Assignment → Response → Resolution → Feedback.

## UX rule
Every important flow must define mobile and desktop behavior, loading, empty, error, offline where relevant, permission denied, cancellation, retry and success states.
