# سند مادر راهبردی مرکز آموزش

## 1. جایگاه
مرکز آموزش یکی از مجموعه‌های زیست‌بوم هوشمند فناوری است و در دو محور فعالیت می‌کند: خدمات تخصصی طراحی/راه‌اندازی سامانه‌های آموزشی و پلتفرم مستقل جامع یادگیری.

## 2. چشم‌انداز
ایجاد زیرساخت هوشمند، فردمحور و موبایل‌محور برای طراحی، ارائه، مدیریت و شخصی‌سازی یادگیری فردی و سازمانی.

## 3. مأموریت
- مشاوره و نیازسنجی آموزش دیجیتال
- طراحی و توسعه LMS، پورتال و سامانه‌های تخصصی
- ارائه SaaS آموزشی
- ایجاد تجربه یادگیری شخصی‌سازی‌شده
- استفاده هدفمند از AI در آموزش
- اتصال آموزش به مهارت، پروژه، ارزیابی و هویت آموزشی

## 4. دو بازوی کسب‌وکار
### A) Services & Solutions
مشاوره، تحلیل، طراحی، توسعه اختصاصی، سفارشی‌سازی، مهاجرت، Integration، پشتیبانی و راهکارهای AI آموزشی.

### B) Education Platform
پلتفرم Personal + Organizational Learning با هسته مشترک Education Core.

## 5. مخاطبان
Learner، Student، Instructor، Author، Mentor، Examiner، Academy، University، Corporate، Enterprise و مدیران آموزش.

## 6. اصول محصول
Person First، Mobile First، AI Ready، Outcome Based، Skill Based، Adaptive Learning، Project Based، Learning Identity، API First، Multi-Tenant Ready، Modular Core و Accessibility.

## 7. فردمحوری
نقطه شروع «فرد» است نه «دوره». سیستم هدف، سطح، زمان در دسترس، علایق، مهارت‌ها، عملکرد و مسیر فرد را می‌شناسد.

## 8. Learning Identity
هر کاربر دارای هویت آموزشی شامل Profile، Goals، Skills، Learning History، Courses، Projects، Assessments، Certificates و Achievements است.

## 9. Goal → Skill → Path
هدف به مهارت‌های لازم نگاشت می‌شود؛ مهارت‌های فعلی سنجیده می‌شوند؛ شکاف تحلیل می‌شود؛ سپس Learning Path شخصی پیشنهاد می‌شود.

## 10. AI
AI یک Chatbot عمومی نیست. AI باید به‌صورت Personal Learning Agent، Instructor Agent، Content Agent، Assessment Agent، Organization Agent و Support Agent در معماری حضور داشته باشد.

## 11. Mobile
Mobile تجربه درجه‌یک است. PWA-ready از ابتدا و Native App پس از تثبیت Core و API توسعه می‌یابد.

## 12. Business Model
درآمد از B2B Services، SaaS، Subscription، Marketplace، Professional Services و در مراحل بعد Mentor/Enterprise AI.

## 13. برند
علمی، حرفه‌ای، انسانی، هوشمند، قابل اعتماد و آینده‌نگر؛ بدون شلوغی بصری و بدون وابستگی افراطی به ترندهای زودگذر.

## 14. Architecture Principles
Modular Monolith در شروع؛ مرزبندی روشن ماژول‌ها؛ PostgreSQL؛ Redis؛ Object Storage؛ API-first؛ AI Gateway؛ Multi-tenant readiness؛ Design System مشترک.

## 15. MVP
Website، Auth، Onboarding، Profile، Course، Enrollment، Lesson، Progress، Quiz پایه، Certificate پایه، Learner Dashboard، Instructor پایه و Admin پایه.

## 16. فازهای توسعه
0 Strategy & Architecture → 1 UX & Design System → 2 Education Core → 3 Learner MVP → 4 Instructor/Admin → 5 Organization/SaaS → 6 Skills/Certificates → 7 AI Learning → 8 Marketplace/Mentor → 9 Mobile/Advanced AI.

## 17. تصمیمات غیرقابل تغییر بدون ADR
Person-first، mobile-first، AI-ready، skill-based، learning identity، modular core، API-first، multi-tenant readiness و design system مشترک.

## 18. معیار موفقیت
تعداد و retention کاربران، completion، بهبود مهارت، استفاده موبایل، تعداد سازمان‌ها، درآمد SaaS و Services، استفاده مفید از AI و کیفیت تجربه یادگیری.
