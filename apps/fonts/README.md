# Persian Fonts

فونت‌های اصلی رابط کاربری مرکز آموزش باید در همین پوشه قرار گیرند.

نام‌های پیشنهادی:
- `Vazirmatn.woff2`
- `Vazir.woff2`

CSS سایت از این فایل‌ها با `@font-face` استفاده می‌کند. فایل واقعی فونت باید توسط مالک پروژه/تیم طراحی در این پوشه قرار گیرد.

قاعده: برای متن فارسی از فونت محلی پروژه استفاده شود و وابستگی اجباری به CDN فونت نداشته باشیم.
