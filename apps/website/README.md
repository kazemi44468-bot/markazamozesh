# Website Demo — مرکز آموزش

نسخه نخست Frontend Demo برای نمایش سریع هویت محصول، خدمات تخصصی و پلتفرم آموزشی.

## وضعیت
- RTL / Persian
- Responsive
- Mobile-first
- Landing page
- Demo course cards
- Learner mobile preview
- AI positioning
- B2B solution sections

## مسیر اجرا
این نسخه فعلاً بدون Backend و با محتوای Demo ساخته شده است. هدف آن اعتبارسنجی سریع ساختار، محتوا و تجربه بصری است؛ سپس صفحات داخلی عمومی به‌صورت مرحله‌ای اضافه می‌شوند.

## اصل توسعه
Frontend و معماری محصول موازی جلو می‌روند؛ Prototypeهای قابل مشاهده مجازند، اما هر تصمیم پایدار باید در docs ثبت شود.
