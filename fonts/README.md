# فونت‌های محلی مرکز آموزش

این پوشه برای فونت‌های فارسی محلی سایت است.

فونت اصلی پیشنهادی: Vazirmatn

لطفاً فایل‌های زیر را در همین پوشه قرار دهید:
- Vazirmatn-Regular.woff2
- Vazirmatn-Medium.woff2
- Vazirmatn-SemiBold.woff2
- Vazirmatn-Bold.woff2
- Vazirmatn-Black.woff2

در صورت نیاز نسخه‌های TTF همین وزن‌ها نیز قابل نگهداری هستند. نسخه WOFF2 برای وب اولویت دارد و TTF به‌عنوان fallback محلی نگهداری می‌شود.
